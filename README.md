# DR : Mayer Ashraf — Physiotherapist

Digital business card (Arabic / RTL) for **DR : Mayer Ashraf**, Physiotherapist.

🔗 **Live:** https://minasaad123.github.io/dr-mayer-ashraf/

## Features
- WhatsApp, direct call, InstaPay payment & one-tap "save contact" (vCard)
- Auto-generated QR code pointing to the live site, downloadable in print quality
- Fully static, no third-party JS at runtime (QRious self-hosted), strict CSP
- SEO: meta description, Open Graph / Twitter cards, JSON-LD, sitemap, robots.txt
- PWA manifest, favicons, optimized WebP/JPEG images, reduced-motion support

## Project structure
```
public/              # Deployed site root
  index.html
  404.html
  assets/css/styles.css   # Generated by Tailwind (do not edit by hand)
  assets/js/app.js        # App logic
  assets/js/qrious.min.js # QR library (vendored)
  assets/img/             # Avatar, OG image, icons
src/input.css        # Tailwind source + custom styles
tailwind.config.js
.github/workflows/deploy.yml  # Builds CSS & deploys to GitHub Pages on push to main
```

## Development
```bash
npm install
npm run dev     # watch & rebuild CSS
npm run serve   # serve ./public on http://localhost:5173
npm run build   # production (minified) CSS
```

Pushing to `main` automatically builds and deploys to GitHub Pages.

> To update contact details, edit `DOCTOR_DATA` in `public/assets/js/app.js` and the matching links in `public/index.html`.
